EN:
To download My Appearance v2, click the green button and the code will download a ZIP file. Click it after the download and open it. If you're on a phone, download Termux; if you're on a PC, download Visual Studio Code.

Instructions for a phone

1. After downloading, open the ZIP archive.
2. Unzip it in Downloads.
3. Open your file manager and find this folder.
4. Click on the file ending in .py.
5. Select Termux.
6. In the command line, enter python main.py.
That's it.
Note: After downloading, be sure to enter the commands below.
apt update
apt upgrade
pkg install python.

If you have any questions, please leave a comment.

Instructions for a PC

1. After downloading, open the ZIP archive.
2. Open the main.py file.

Note: Visual Studio Code is required.
If you encounter any difficulties, please leave a comment.
